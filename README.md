（象脚鼓、凤凰花、银碗、柏树叶）
**参考答案**（用上所给词语）：

周总理来到人群中，接过一只**象脚鼓**，敲着欢乐的鼓点，踩着**凤凰花**铺成的“地毯”，同傣族人民一起跳舞。开始泼水了，周总理一手端着盛满清水的**银碗**，一手拿着**柏树叶**蘸了水，向人们轻轻泼洒，祝福大家健康长寿。清清的水泼啊洒啊，周总理和傣族人民笑啊跳啊，度过了这个幸福又难忘的泼水节。

**朗读小提示**：
- “多么幸福啊，1961年的泼水节！”“多么令人难忘啊，1961年的泼水节！”——两句要用感叹语气，读出又幸福又难忘的感情。
- “清清的水，泼啊，洒啊！”——“泼啊”“洒啊”要读得轻快、欢腾，像水花飞起来一样。

从课文中找出描写周总理样子的句子读一读。
课文中描写周总理样子的句子是：

> **周总理身穿对襟白褂、咖啡色长裤，头上包着一条水红色头巾，笑容满面地来到人群中。**

**这句话写了周总理的穿着打扮**：

| 部位 | 样子 |
|---|---|
| 上身 | 对襟白褂 |
| 下身 | 咖啡色长裤 |
| 头上 | 水红色头巾 |
| 神态 | 笑容满面 |

**朗读小提示**：
- “对襟白褂、咖啡色长裤、水红色头巾”——这几个词语读清楚，仿佛能看到周总理这身漂亮的傣族服装。
- “笑容满面”——读出亲切、温暖的感觉，让人感到周总理是发自内心地高兴。

## 一、课文的"作者标注"问题

现行部编版教材的课文注释写的是：
> **"本文选自《永恒的纪念：周总理的文物》，编者锺庆，选作课文时有改动。"**

但根据文学研究者的考证，这个标注存在争议——《永恒的纪念：周总理的文物》一书出版于1978年12月，而《难忘的泼水节》早在1978年8月就已经首次出现在小学教材中，时间上矛盾。此外，该书的文体和内容与现行课文差异很大。

实际上，现行课文是**综合改编**而成的：
- 框架来自白族作家**张长**的散文《泼水节的怀念》
- 部分细节补充自回忆录《金孔雀开屏的时候》（又名《周总理在西双版纳的日日夜夜》）

### 生平经历

张长1956年毕业于昆明医士学校，最初是一名**乡村医生**，后来先后担任文化馆工作人员、云南省文化局创作室编辑、《大西南文学》编委。1957年开始发表作品，1979年加入中国作家协会。

他的文学之路与**西双版纳**密不可分——正如他自己所说：
> "西双版纳是我文学之路的起点，我在那里写了第一首诗，第一篇散文，第一篇小说。可以说，没有西双版纳的生活就没有我的今天。"

### 主要成就

- **四次获得中国作家协会文学奖**（含鲁迅文学奖、骏马奖）：
  - 《空谷兰》——1979年全国优秀短篇小说奖（后纳入鲁迅文学奖）
  - 《希望的绿叶》——第一届全国少数民族文学奖
  - 《最后一棵菩提》——第二届全国少数民族文学奖
  - 《太阳树》（长篇）——第五届骏马奖

- **2006年获云南省文学艺术成就奖**

- 著有诗集、散文集、中短篇小说集、长篇小说共**约20部**，2012年出版《张长文集》6卷。作品被译成英、法、日文。

## 三、与课文的关系

张长的散文《泼水节的怀念》写于上世纪70年代末，饱含深情地回忆了1961年周恩来总理在西双版纳与傣族人民共度泼水节的历史场景。这篇文章情感真挚、画面感强，是现行二年级课文《难忘的泼水节》的主要文学源头。

课文编者在此基础上，结合其他回忆文章的细节，进行了适合小学生阅读的改编，最终形成了我们今天看到的课文版本。

---

**简单总结**：如果教学中要提作者，可以这样说——"《难忘的泼水节》是根据白族作家张长的散文《泼水节的怀念》改编而成的，选作课文时有较大改动。" 这样既准确又符合实际情况。
